# 나는 이번생은 양일고다!

경기도 양평 양일고등학교를 배경으로 한 학교생활 시뮬레이션 게임입니다. 무작위 능력치로 입학해서 3년을 보내고, 졸업 엔딩과 졸업 카드를 받습니다.

- **실제 친구 모드**: 친구들이 모두 실제 양일고 친구들이에요. 본인 허락을 받고 출연했고, 좋은 이야기만 나옵니다.
- **연애 모드**: 가상 친구 4명과 우정·연애. 실제 친구들은 우정 에피소드에만 조연으로 나와요.

## 실행

빌드 과정이 없는 정적 웹페이지예요. `index.html`을 브라우저로 열면 바로 됩니다. GitHub Pages로 배포합니다.

## 참고

학교 정보는 공개 자료를 참고했습니다. 학교 공식 게임이 아닌 학생 팬 게임이에요. 저장 기록은 각자 브라우저(localStorage)에만 남습니다.
