# 학기말 보스전 · 친구 도감 · 3학년 2학기 시험 삭제 설계

## 왜 만드나
- 서준 님 피드백: **2학년 중반부터 지루하다.** 1학년~2학년 1학기에 새 요소가 다 열리고, 이후엔 같은 행동과 사건이 반복되며, 수학여행 뒤로 큰 목표가 멀다.
- 보스전은 **"내가 했던 공부가 무기가 되는"** 학기말 이벤트로, 학기마다 목표와 긴장감을 준다. 서준 님이 "퀄리티가 높았으면 좋겠다"고 한 기능이다.

## 목표 / 하지 않을 것 / 실패 기준
- 목표
  - 학기 1차 시험 뒤 남은 날이 "보스 대비 기간"이 되게 한다.
  - 공부(과목 숙련도·오답노트)가 전투에서 실제로 힘이 된다.
  - 타이밍 바로 손맛, 보스 예고 공격으로 판단하는 재미를 준다.
- 하지 않을 것
  - 전투 중에 과목 문제를 풀게 하지 않는다. (서준 님 요청)
  - 1차 시험은 전투가 아니다. (서준 님 요청)
  - 연속 스토리 · 2학년 해금 · 콤보는 이번 범위가 아니다. (다음 설계)
- 실패 기준
  - 전투가 시험 점수를 크게 흔들어 랭킹·S등급 밸런스가 깨진다.
  - 전투가 길고 반복적이어서 오히려 지루하다.
  - 실제 친구가 나쁜 역할로 나온다. (최종 보스 염서준은 서준 님 본인이라 예외, 본인 확인 완료)

## 정한 것 (서준 님 결정)
1. **성적 반영 방식: 섞기.** 기본 점수는 지금처럼 공부량으로 정해지고, 전투 결과로 **±10점 안쪽**에서 더하거나 뺀다.
2. **전투 방식: 전략형 + 타이밍 바.** 매 턴 과목 스킬을 고르고, 타이밍 바를 눌러 공격한다. 과목 문제는 없다.
3. **빈도: 2차(학기말)만 보스전.** 1차는 "전투 준비"다.
4. **3학년 2학기 시험은 없앤다.** (양일고는 3학년 2학기 정기시험을 보지 않음)
5. **보스 5명**
   | 학기말 | 보스 | 약점 / 내성 | 특징 |
   |---|---|---|---|
   | 1-1 | 은행왕 (은행나무길 거대 은행나무) | 과학 / 사회 | 「은행 열매 폭탄」 2턴 지속 피해. 2단계 「겨울 은행왕」 |
   | 1-2 | 다목적관 LED 스크린 | 매 턴 바뀜 | 「화면 전환」 약점이 매 턴 바뀜, 「블루스크린」 1턴 기절 |
   | 2-1 | 사물함 미믹 | 수학 / 국어 | 「프린트 폭풍」 3연타 |
   | 2-2 | 야자의 유령 (밤 10시 자습실, 형광등 깜빡임) | 과학 / 국어 | 「졸음 주문」 2턴 동안 타이밍 바가 빨라짐 |
   | 3-1 최종 | 양일고 본관 → 게임 제작자 염서준 | 1단계 사회 / 영어, 2단계 매 턴 바뀜 | 체력 절반에서 화면이 지지직거리며 염서준 난입. 「밸런스 패치」, 「버그 소환」, 「핫픽스」 |
6. **구현 방식: 지금 게임처럼 SVG 그림 + CSS 애니메이션.** (캔버스·게임 엔진은 그림체가 안 맞고 무거워서 제외)
7. **친구 도감**: 기록 갤러리 안에 「졸업생 | 친구 도감」 탭. 실제 친구 50명 카드(만남 여부, 최고 우정 ★, 별명, 본 에피소드 수, 누르면 롤링페이퍼·10년 뒤). 가상 친구 제외.

## 검토한 방법 (Approaches)
- 성적 반영: ① 전투 = 시험 점수 / ② 연출만 / **③ 섞기(선택)** — ①은 랭킹 밸런스를 다시 맞춰야 하고 ②는 싸우는 느낌이 약하다.
- 전투: **A 과목 스킬(선택, 문제 대신 전략+타이밍)** / B 타이밍만 / C 카드 덱 — B는 공부와 연결이 약하고 C는 규칙이 길다.
- 구현: **① SVG+CSS(선택)** / ② 캔버스 / ③ Phaser — ②③은 그림체 불일치·무게 문제.

## 흐름
### 1차 정기시험 (전투 준비)
- 점수 계산은 지금 그대로.
- 결과 뒤에 **「정찰 보고서」** 카드: 이번 학기말 보스 이름·그림 실루엣·약점·내성 공개. "남은 날 동안 ○○를 공부하면 유리해요."
- **장비**: 1차에서 1~2등급 과목은 보스전에서 그 과목 스킬 **+1레벨**, 4등급 이하 과목은 보스가 「약점 공략」으로 노린다(그 과목 스킬 −1레벨).
- 정찰 결과는 `S.bossPrep[semKey]`에 저장하고, 메인 화면 D-day 옆에 「학기말 보스: ○○ D-3」을 띄운다.

### 2차 정기시험 (보스전)
- 시험 날 선택지: 「실력대로」 → 보스전 시작 / 「찍기 신공」 · 「시 쓰기」 → 지금처럼 바로 계산(전투 없음).
- 전투 → 결과 화면(보스 처치 연출 + "전투 보너스 +7점") → 지금의 시험 결과(과목별 점수·등급) 그대로 이어서.

## 전투 규칙 (빌더 기본값, 시뮬레이션으로 조정)
- **내 집중력**: 100에서 시작, 피로가 50을 넘은 만큼의 절반을 빼고 시작.
- **턴 수**: 최대 8턴. 8턴이 지나면 "시험 종료" 종이 울리며 끝.
- **스킬 카드**: 이번 학기 수강 과목마다 1장. 과목 영역(국어·수학·영어·사회·과학 등, `sub.area`) 기준으로 약점·내성 판정.
  - 레벨 = 숙련도 ÷ 10(내림) + 장비 보정.
  - 데미지 = (8 + 레벨 × 2.2) × 약점 2배 / 내성 0.5배 × 타이밍 배수.
- **타이밍 바**: 좌우로 움직이는 커서. 가운데 「완벽」(×1.5, 크리티컬 연출), 그 옆 「좋음」(×1.0), 바깥 「아쉬움」(×0.6), 놓치면 「빗나감」(×0.2). 학년이 오를수록 빨라진다. 탭·클릭·스페이스로 누른다. 설정의 「미니게임 자동 넘김」이 켜져 있으면 자동으로 「좋음」, 동작 줄이기 설정이면 느리게.
- **보스 예고**: 매 턴 보스가 다음 공격과 "막을 수 있는 과목"을 보여 준다. 그 과목 스킬로 공격하면 공격도 하고 막기도 한다. 막지 못하면 집중력이 깎이거나 효과(지속 피해, 봉인, 기절 등)가 걸린다.
- **복수 공격**: 오답노트에 문제가 있으면 전투당 최대 3번. 내성 무시 ×2.5. 쓸 때마다 오답노트 한 문제를 "복수 성공"으로 지운다.
- **친구 응원**: 친밀도 70 이상인 이번 판 친구 중 한 명이 전투당 한 번 등장(회복, 2연타, 효과 해제, 다음 예고 공개 중 하나). 친구 이름과 대사를 보여 준다. 실제 친구는 늘 돕는 쪽으로만 나온다.
- **2단계**: 보스 체력 50%에서 변신 연출 + 패턴 변화.
- **점수 보너스**: 처치하면 +6~+10(남은 집중력 비례), 집중력 0이면 −10~−4(보스 남은 체력 비례), 시간 종료면 깎은 비율로 −4~+5. 모든 과목 지필 점수에 같은 값을 더한다.
- **밸런스 목표**: 보통 플레이 평균 +0~+4, 잘하는 플레이 +7 이상. 기존 점수 계산·등급 기준(S 103 · A 94)과 Firestore 규칙은 바꾸지 않는다.

## 화면
```
┌ 2학년 2학기 2차 정기시험 · 야자의 유령 ─────────┐
│ [배경: 밤 자습실, 형광등 깜빡임]                   │
│            (보스 그림 · 둥실둥실)    HP ███████░░░  │
│ 다음 턴 ▶ 「졸음 주문」  과학으로 막을 수 있음      │
│ 나 · 집중력 ██████░░   턴 3 / 8                    │
│ [국어 Lv5 내성] [수학 Lv7] [과학 Lv6 약점] [영어 Lv4] │
│ [복수 공격 ×2]  [응원: 이하연]                      │
│ ├────────░░▓▓█▓▓░░────────┤ ← 타이밍 바            │
└────────────────────────────────────────────────────┘
```
- 보스는 320×180 장면 위에 크게 그린 SVG. 기본 둥실거림, 피격 시 하얀 번쩍임 + 흔들림, 데미지 숫자 튀어 오름, 크리티컬은 화면 흔들림.
- 배경은 기존 장면 배경 재사용(은행나무길, 강당, 복도, 교실+밤 연출, 학교 전경).
- 최종전 2단계: 화면 지지직(글리치) 연출 → 염서준 아바타(기존 아바타 그림) + 노트북.
- 휴대폰 400px에서 가로 넘침 없이. 스킬 카드는 2줄로 접힌다.

## 기록
- 보스 처치 기록을 도감에 저장(`dex.bosses`), 도감에 「보스 도감」 칸.
- 졸업 기록에 학기별 보스 결과를 남겨 졸업 화면 "3년 기록"에 보여 준다.

## 3학년 2학기 시험 삭제
- 3학년 2학기에는 1차·2차 정기시험이 안 나온다. 그 학기 성적표(학기 최종 성적)는 만들지 않고, 내신은 3학년 1학기까지로 계산한다.
- 수시 원서·수능·합격 발표·졸업 앨범 등 다른 행사는 그대로.

## 빌더에게 맡기는 것
- 보스 그림의 세부 디자인, 공격 이름 외 대사, 애니메이션 타이밍.
- 위 숫자들의 최종값(시뮬레이션으로 목표 분포에 맞춤).
- 자동 시뮬레이션(bal3 등)이 전투를 자동으로 끝낼 수 있게 하는 자동 전투 함수.
- 친구 응원 효과를 친구별로 정할지, 성격(likes)별로 정할지.
