# 반복 줄이기 (짧은 설계)

서준 님 피드백: "같은 선택지나 질문이 나오면 지루하다" → A·B·C·D 모두 고친다. (승인: 2026-11-13)

- 측정: 한 판 사건 64개 중 반복 11개(17%). 친구 대사는 단계마다 3줄(공통 2 + 고유 1). 문제는 약 200개를 중복 허용으로 뽑음. 학교 행사 10종은 학년과 상관없이 같은 선택지.
- D 일상 사건: 한 판에서 본 일상·병맛·희귀 사건은 다시 안 나온다(친구가 바뀌는 템플릿 사건 favor_ask·duo·pair_scene·sig_*·연애 사건은 예외). 새 일상 사건 15개.
- B 공부 문제: 한 판에서 푼 문제(문항 텍스트 기준)는 다시 안 나온다. 다 쓰면 그 주제만 초기화. 과목 주제마다 문제 추가(약 +100).
- C 친구 대화: 공통 대사 단계마다 2→6줄, 실제 친구 50명 고유 대사 단계마다 2줄(총 8줄), 직전 대사 연속 금지.
- A 학교 행사: 정기시험·모의고사·수행평가·체육한마당·축제·응원전·Y리그·과학의 날·체험학습·학생회 모집에 학년별 상황 글과 선택지 변형. 정기시험 「실력대로」는 고정, 나머지 두 개는 우스운 선택지 풀에서 매번 다르게.
- 목표: 반복률 5% 미만. 실제 친구는 부정적 내용 금지, 연애 금지 원칙 유지.
