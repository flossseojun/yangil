# ⑥ 이야기: 연속 스토리 · 2학년 2학기 해금 · 콤보 · 콜백

## 1. 연속 스토리 (2학년 2학기 ~ 3학년 1학기)
2학년 2학기 첫날, 지금까지의 활동 횟수(S.counts)를 보고 둘 중 하나가 자동으로 시작된다.

- 축제형 = 대화 + 약속 + 학생회 × 1.5
- 동아리형 = 자율동아리 × 1.5 + 동아리 + 탐험 × 0.5
- 자율동아리에 가입하지 않았으면 무조건 녹향제 기획단. 동점이면 녹향제 기획단.
- 시작 사건에서 "지금까지 친구들과 보낸 시간이 많아서…" / "자율동아리에 쏟은 시간이 많아서…"처럼 왜 이 이야기가 왔는지 한 줄로 알려 준다.

### A. 녹향제 기획단 (마지막: 3학년 1학기 녹향제)
| 장 | 언제 | 내용 |
|---|---|---|
| 1 | 2-2 1일 | 학생회 선배가 "내년 녹향제 기획단 해 볼래?" 제안. 함께할 친구 2명이 자동 합류(친밀도 높은 실제 친구) |
| 2 | 2-2 3일 | 주제 정하기 회의. 선택이 축제 콘셉트(레트로 / 남한강 / 공포)를 정한다 |
| 3 | 2-2 7일 | 예산 사고: 예산이 반으로 깎였다. 발로 뛰기(체력) / 기업 후원 편지(사교) / 직접 만들기(전문) |
| 4 | 3-1 1일 | 후배 모집. 1학년 후배들이 들어온다 |
| 5 | 3-1 4일 | 리허설 대참사. 앞에서 쌓은 준비도에 따라 수습 정도가 달라진다 |
| 6 | 3-1 6일 | 녹향제 당일 특별 컷신 + 결말 |

### B. 자율동아리 대회 (마지막: 3학년 1학기 자율동아리 탐구 발표대회)
가입한 자율동아리(로보틱스 / 버터구이 / 시드핸즈 / 워터스캔)에 맞춰 내용이 바뀐다.
| 장 | 언제 | 내용 (버터구이 예시) |
|---|---|---|
| 1 | 2-2 1일 | 부장(시아)이 대회 공고문을 들고 온다. "우리 이번엔 나가 보자." |
| 2 | 2-2 3일 | 탐구 주제 정하기. 선택이 주제를 정한다 (체색 변화 / 알 부화율 / 수조 자동화) |
| 3 | 2-2 7일 | 실험 실패. 수조 히터 고장. 밤새 지키기 / 지용에게 부탁 / 처음부터 다시 |
| 4 | 3-1 1일 | 후배 부원 들어옴. 기록을 물려줄지 함께할지 |
| 5 | 3-1 4일 | 예선 발표. 발표 미니게임(순서 맞추기 재사용) |
| 6 | 3-1 6일 | 본선 발표 특별 컷신 + 결말 |

### 결말 (공통 3단계)
- 준비도 = 각 장의 선택 점수 + 그 기간의 해당 활동 횟수
- 대성공: 업적 + 특별 별명 + 졸업 롤링페이퍼에 언급 + 세특 문장 1줄
- 무난: 따뜻한 마무리 + 작은 보너스
- 아쉬움: 실패지만 친구들과 웃는 결말 (부정적 내용 없음)

## 2. 2학년 2학기 해금
- 「새 학기, 새 시즌」 알림 창 (무엇이 열렸는지 보여 줌)
- 새 행동 「후배 챙기기」: 사교↑ 평판↑, 1학년 후배 사건이 나온다
- 새 탐험 장소 「방송실」: 점심 방송 사건 몇 개

## 3. 콤보 (3일 연속 같은 행동)
- 같은 친구와 3일 연속 대화 → 그 친구 특별 사건
- 자습 3일 연속 → 「몰입」: 다음 자습 효과 ×2
- 운동 3일 연속 → 「컨디션 최고」: 다음 날 피로 회복 ↑
- 화면 위에 콤보 칸(🔥2/3)이 보인다

## 4. 콜백 (예전 선택을 기억하기)
- 주요 선택(축제 콘셉트, 수학여행 밤, 보스 승리 등)을 S.memo에 기록
- 친구 대화, 롤링페이퍼, 에필로그에서 "그때 너 ○○했잖아" 식으로 언급

## 지키는 규칙
- 실제 친구는 좋은 역할로만 나온다 (연애·질투·부정적 내용 없음)
- 실제 선생님 이름은 쓰지 않는다 ("학생회 담당 선생님")
